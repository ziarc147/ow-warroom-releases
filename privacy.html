개인정보처리방침

오그리마와이번스 전투정보실 (이하 "앱") · 시행일 2026-11-08

요약: 앱은 내 PC 와 내 구글 드라이브 사이에서만 파일을 주고받아요. 개발자나 다른 서버로 보내는 개인정보는 없어요.

1. 구글 계정으로 접근하는 정보

권한쓰는 곳
https://www.googleapis.com/auth/drive.file 앱이 내 드라이브에 만든 OW전투정보실 폴더와 그 안의 파일(와우 애드온 설정·폰트, 파일 목록 manifest.json)을 만들고, 읽고, 고치기. 앱이 만들지 않은 드라이브 파일은 볼 수 없어요.
openid, email 앱 화면에 "어느 구글 계정이 연결됐는지" 이메일 주소를 보여 주기 위해서만 써요.

2. 저장하는 정보와 위치

  • 구글 로그인 토큰: 내 PC 의 %LOCALAPPDATA%\OWWarroom\ 폴더에 윈도우 암호화(DPAPI)로 저장. 같은 PC 의 같은 윈도우 사용자만 풀 수 있어요.
  • 앱 설정(와우 폴더 위치, 계정 폴더 이름 등): 같은 폴더의 settings.json.
  • 와우 애드온 설정·폰트: 내 구글 드라이브의 OW전투정보실 폴더. 파일마다 원래 경로, 해시(sha1), 수정 시각, 올린 PC 이름이 함께 기록돼요.

개발자는 위 정보 어느 것에도 접근할 수 없어요. 앱에는 분석·광고·추적 기능이 없어요.

3. 외부와 주고받는 통신

  • Google (로그인, 구글 드라이브 API) — 위 1번의 목적에만.
  • GitHub (api.github.com) — 새 버전이 있는지 확인. 개인정보는 보내지 않아요.

4. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API 로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy (제한적 사용 요구사항 포함)를 따릅니다. 받은 정보를 사람이 읽거나, 광고에 쓰거나, 제3자에게 넘기지 않습니다.

5. 연결 해제와 삭제

  • 앱의 설정 → 구글 드라이브 → 연결 해제: PC 에 저장된 토큰을 지우고 구글에 권한 취소를 요청해요.
  • 구글 계정에서 직접: Google 계정 → 보안 → 타사 액세스 에서 앱을 삭제.
  • 드라이브에 올린 파일은 내 드라이브의 OW전투정보실 폴더를 지우면 모두 삭제돼요.
  • PC 의 앱 데이터는 %LOCALAPPDATA%\OWWarroom\ 폴더를 지우면 삭제돼요.
